An offline guide + tracker for all 55 GTA 6 PlayStation trophies: official names, descriptions and grades, a cited guide for every trophy, a roadmap to the platinum, missable flags, and a checklist that saves in your browser (localStorage) with export/import, kind filters, and a spoiler setting that hides story trophy names until earned.

Open `app/index.html` in a browser — no network needed, no build step.
